==============================
Partie 2 — Le langage CSS
==============================

CSS (Cascading Style Sheets) est le langage de **mise en forme** du Web. Là où HTML structure le contenu, CSS lui donne vie : couleurs, polices, espacements, animations, mise en page responsive...

Dans cette deuxième partie, tu apprendras à transformer des pages HTML brutes en interfaces visuelles soignées et professionnelles.

----

.. admonition:: Objectifs de la Partie 2
   :class: tip

   À la fin de cette partie, tu sauras :

   - ✅ Lier une feuille de style CSS à un fichier HTML
   - ✅ Utiliser les sélecteurs CSS (élément, classe, id, pseudo-classes)
   - ✅ Maîtriser le modèle de boîte (box model)
   - ✅ Mettre en forme textes, couleurs et fonds
   - ✅ Créer des mises en page avec Flexbox et CSS Grid
   - ✅ Rendre un site responsive avec les Media Queries
   - ✅ Intégrer des polices web (Google Fonts) et des icônes

----

.. admonition:: Prérequis
   :class: note

   Cette partie suppose que tu as terminé la **Partie 1 — HTML** et que tu sais créer une page HTML valide avec des balises sémantiques.
